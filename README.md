# travel-control-tower-preview-20260411

Public preview deployment source for Travel Control Tower.

## Built-in featured itinerary

The home page links to a packaged Hangzhou–Singapore–Penang–Bali–Kuala Lumpur itinerary:

- `/featured` — complete visual itinerary
- `/featured/plan` — source JSON
- `/featured/excel` — downloadable workbook
- `/featured/map` — route SVG
- `/trips` — saved-trip workspace
